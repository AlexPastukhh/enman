# Clean Data Requirements

Status: draft

## Данные клиента

[IMPLEMENTED]

- email;
- пароль при регистрации;
- хеш пароля в хранилище;
- роль пользователя;
- признак активности;
- дата создания аккаунта.

## Данные заявителя-физического лица

[IMPLEMENTED]

- имя;
- отчество;
- фамилия;
- email;
- номер телефона;
- идентификатор клиентского аккаунта.

## Данные заявки

[IMPLEMENTED]

- идентификатор заявителя;
- тип заявки;
- статус заявки;
- описание заявки;
- адрес объекта;
- дата создания.

## Адрес объекта

[IMPLEMENTED]

Адрес объекта должен храниться как структурированное значение:

- почтовый индекс;
- регион;
- город;
- улица;
- дом;
- корпус;
- квартира или помещение.

## Данные обработки заявки сотрудником

[DESIGNED]

- сотрудник, взявший заявку в обработку;
- дата начала обработки;
- результат проверки;
- статус после проверки;
- причина отклонения, если заявка отклонена;
- дата принятия решения.

## Данные проекта договора или документа

[DESIGNED/PLANNED]

- идентификатор связанной заявки;
- идентификатор клиента;
- название или тип документа;
- файл или ссылка на файл;
- комментарий сотрудника;
- статус документа;
- дата создания;
- дата отправки уведомления.

## Данные email-уведомления

[PLANNED]

- адрес получателя;
- тема письма;
- текст уведомления;
- связанное событие;
- дата отправки;
- результат отправки.
