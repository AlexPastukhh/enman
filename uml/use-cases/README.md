# Use Case диаграммы (PlantUML)

Файлы диаграмм лежат в папке `uml/use-cases/`.

## Как посмотреть/экспортировать

Вариант 1 (VS Code): установить расширение **PlantUML** и открыть `.puml` файл.

Вариант 2 (CLI): использовать PlantUML (jar) или любой поддерживаемый рендерер.

## Состав

- `usecase_01_registration.puml` — регистрация
- `usecase_02_auth_password_reset.puml` — вход и восстановление пароля
- `usecase_03_profile_phone_verify.puml` — доп. данные и подтверждение телефона
- `usecase_04_create_request.puml` — создание запроса
- `usecase_05_admin_review.puml` — обработка заявок админом
