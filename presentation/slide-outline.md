# Slide Outline

Status: draft

## 1. Титульный слайд

Тема: «Разработка web-приложения для автоматизации ведения документооборота и обработки клиентских заявок в сетевой компании ООО „ЗСК“»

На слайде:

- ФИО студента;
- группа;
- руководитель;
- вуз, кафедра;
- год.

## 2. Организация и предметная область

На слайде:

- ООО «ЗСК» — условная сетевая компания;
- обработка клиентских заявок;
- ручная проверка заявок сотрудником;
- подготовка договорных документов.

## 3. Выявленная проблема

На слайде:

- разрозненная обработка заявок;
- ручной контроль статусов;
- риск ошибок в данных;
- отсутствие единой связи между заявкой и документом;
- задержка информирования клиента.

## 4. Цель работы

Цель:

> Разработать web-приложение для автоматизации ведения документооборота и обработки клиентских заявок в сетевой компании ООО «ЗСК».

## 5. Задачи работы

На слайде:

- анализ предметной области;
- формирование требований;
- проектирование доменной модели;
- проектирование БД;
- разработка backend;
- разработка frontend;
- реализация базовых сценариев клиента;
- проектирование обработки заявки сотрудником;
- тестирование.

## 6. Пользователи системы

На слайде:

- клиент;
- сотрудник сетевой компании.

## 7. Основной сценарий клиента

На слайде:

1. Регистрация.
2. Вход.
3. Создание заявителя-физического лица.
4. Подача заявки.
5. Просмотр статуса.
6. Получение уведомления.

## 8. Основной сценарий сотрудника

На слайде:

1. Просмотр списка заявок.
2. Взятие заявки в обработку.
3. Ручная проверка.
4. Одобрение или отклонение.
5. Создание проекта договора при одобрении.

## 9. Жизненный цикл заявки

Диаграмма:

```text
Создана
-> На рассмотрении / В обработке
-> Одобрена / Отклонена
-> Проект договора создан
```

## 10. Документооборот

На слайде:

- проект договора создается после одобрения заявки;
- документ связан с клиентом и заявкой;
- клиент получает email-уведомление;
- дальнейшее развитие — версии документов и электронное подписание.
