## 0. Карта размещения

### Карта ВКР

```text
ВКР
├─ Введение
├─ Глава 1. ...
│  ├─ 1.1 ...
│  │  └─ Текущая тема: ...
│  └─ ...
├─ Глава 2. ...
├─ Глава 3. ...
└─ Заключение
```

### Карта рабочей базы тем

```text
planning/thesis/vkr-topic-workbench/
└─ ...
   └─ ...
      └─ <topic-file>.topic.md
```

### Роль темы в структуре

Кратко объяснить:

- какой пункт ВКР раскрывает тема;
- что эта тема готовит для соседних пунктов;
- что эта тема готовит для следующих глав;
- что не входит в эту тему.
