# Правила и workflow рабочей базы тем ВКР

Статус: актуально / русскоязычный topic-first workflow / research bridge добавлен

Эта папка содержит правила работы с материалами ВКР до написания полных черновиков разделов.

## Основная идея

Сначала собирается смысловая база темы, затем исследовательская привязка, визуалы и только после этого пишется полный текст:

```text
карта главы
→ тема
→ обсуждение содержания
→ что требуется обосновать
→ вопросы для конкретизации
→ исследовательская привязка
→ границы утверждений
→ рисунки и таблицы
→ карта будущего текста
→ черновые фрагменты
→ полный черновик раздела
```

## Research материалы

Research-материалы хранятся отдельно:

```text
planning/thesis/vkr-topic-workbench/00-research-materials/
```

Они не являются готовым текстом ВКР. Их задача — отвечать на вопросы, которые возникают из topic-драфтов.

Правильный порядок использования:

```text
тезис темы
→ вопрос к research
→ короткий ответ из research
→ переработка под нашу предметную логику
→ место в будущей карте текста
```

Нельзя вставлять research буквально большими кусками. Нужно перерабатывать его под flow главы.

## Правило языка

Смысловые материалы ВКР пишутся на русском языке. Английские имена допускаются только для технологий, стандартов, классов, файлов и терминов кода, если они нужны для точности.

Пример:

```text
Правильно: Статус: нужен сбор материалов
Нежелательно: Status: material-harvest-needed
```

## Правило примеров

Если пользователь не говорит иначе, новые темы и драфты следует делать по последнему принятому формату. Принятые темы и драфты использовать как примеры структуры, глубины и стиля.

## Вопросы для конкретизации

В каждом topic-драфте допускается и желательно держать вопросы. Они нужны не как “авторское мнение”, а как рабочий инструмент будущей генерации текста:

```text
topic-драфт
→ вопросы для конкретизации
→ ответы / repo-check / research-check
→ первый текстовый черновик
```
