# Drafting algorithms

This directory controls how chats draft topic files and section drafts.

## Files

```text
topic-draft-default-flow.md
topic-clarify-and-recheck-flow.md
topic-to-section-block-drafting.md
section-draft-generation.md
question-generation-for-drafts.md
```

## Core rule

A draft is not generated by improvisation. It is generated by:

```text
source materials
→ questions
→ default answers / variants
→ section blocks
→ plan of disclosure
→ draft text
```
