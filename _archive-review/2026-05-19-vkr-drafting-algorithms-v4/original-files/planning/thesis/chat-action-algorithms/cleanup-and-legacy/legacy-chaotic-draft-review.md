# Algorithm: legacy chaotic draft review

Run when the user sends or identifies a chapter/section draft made without the current workflow.

## Storage

Place/reference it under:

```text
planning/thesis/vkr-clean/legacy-chaotic-drafts/
```

## Rules

1. Do not treat it as a clean section draft.
2. Do not copy it into VKR directly.
3. Review:
   - useful ideas;
   - inaccurate statements;
   - template-like text;
   - overclaiming;
   - structure problems;
   - paragraphs worth rewriting;
   - what the current workflow should prevent.
4. Convert useful material into topic-draft questions or section blocks.
