# Section drafts

This folder stores developing VKR text.

## Main rule

Section drafts are built by blocks.

```text
topic semantic block
→ questions
→ source materials
→ plan of disclosure
→ section draft block
→ text
```

Do not create a section draft as a single uncontrolled text wall.

## No fragment bank

There is no mandatory `fragment-bank.md`. Section draft itself is where text accumulates.

If a generated paragraph is good, put it into the relevant section block. If its place is unclear, return to the topic draft and decide the section block.

## Required before writing a section block

1. Which topic draft feeds this block?
2. Which question does the block answer?
3. Which source materials support it?
4. Does it need research bridge?
5. Does it need repo/evidence check?
6. Does it need a visual?
7. What overclaim risk exists?
