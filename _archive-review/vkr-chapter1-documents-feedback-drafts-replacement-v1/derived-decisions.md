## 1.2.2

- Use term “сотрудник”.
- Version sender: клиент or сотрудник.
- Different employees may support the organization side of the exchange.
- Metadata are stored in SQL Server.
- File is stored in filesystem storage.
- Current file storage is simple directory-based storage for diploma scope.
- Exact metadata fields must be checked in scenario-layer data files.
- Do not claim full ECM/СЭД, legally significant ЭДО, electronic signature, industrial storage, external storage service, or full file audit.

## 1.2.3

- Feedback is broader than notifications.
- Separate: status = process state; decision result = outcome; notification = message/display of significant change.
- In request stage feedback mostly informs the client.
- In contract stage feedback becomes two-way: client can agree, ask a question, or send their own version.
- Do not claim email, push, external notification service, read/unread notification history without repo-check.
