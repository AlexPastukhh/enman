# SC-17 — Anonymous Request

## Status
Future / extension scenario specification draft.

## DATA
Anonymous request DATA `SC-17-DATA-01`: requested service / request subject information; description/details needed to understand request.

Follow-up contact DATA `SC-17-DATA-02`: reachable follow-up contact, email or phone exact channel not fixed.

## Invariants
Anonymous request must have reachable follow-up contact data. Invalid anonymous request/contact data is not accepted.

## Open Questions
Does anonymous request create full request, contact request, or draft?
