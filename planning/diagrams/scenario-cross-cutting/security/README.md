# Cross-Cutting Security Behavior Sources

Status: current source folder
Doc version: v0.1.0  

This folder owns security/protection/abuse scenarios.

These docs describe:

```text
dangerous flows
threats we avoid
required protection behavior
server rejection behavior
client handling behavior when relevant
```

Implementation belongs in server/client slice drafts.

Use umbrella docs in:

```text
planning/slices/cross-cutting/
```

when a concern has multiple side-specific drafts.
