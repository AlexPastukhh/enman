# Cross-Cutting Client Behavior Sources

Status: current source folder
Doc version: v0.1.0  

This folder owns common client behavior required by multiple UI/client scenarios.

Examples:

```text
deferred validation
common feedback/error visibility
flow navigation behavior
loading/empty/error state behavior
```

These files are not implementation drafts.

Client implementation drafts go to:

```text
planning/slices/client/cross-cutting/
```

If the behavior is client-only, the implementation draft should use `SINGLE-` prefix.
