# Scenario DATA Specification

Status: compatibility pointer
Doc version: v0.1.0  

Scenario DATA is now split by scenario. Use:

```text
planning/diagrams/scenario-data/00-scenario-data-index.md
```

DATA = what actor enters, sees, selects, filters by, or attaches/uploads. DATA files must not contain validation/rules, testable behavior, invariants, branches, access rules or security policy.
