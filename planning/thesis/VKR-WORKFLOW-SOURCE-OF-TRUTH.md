# VKR workflow source of truth

## Main workflow

```text
user notes / source-pass
→ roadmap / chapter roadmap
→ active topic drafts
→ scenarios/domain/process rules
→ research
→ visual bridge
→ existing/old draft fallback if needed
→ topic draft or full VKR text version
```

## Research location

Research files are stored in:

```text
planning/thesis/vkr-topic-workbench/00-research-materials/
```

Use `research-index.md` before using a research file.

Research is not pasted literally into VKR text. Use it through:

```text
question from draft
→ research answer
→ project-specific conclusion
→ text/block
```

## Old drafts / ready chapters priority rule

Old ready chapters, existing section drafts and legacy chaotic drafts are valid candidate material, but they are not default first sources.

Default order for topic-draft chats:

```text
1. Active topic drafts and confirmed roadmap decisions.
2. Roadmap/raw notes as cautious source.
3. Scenarios and subject/process rules.
4. Research.
5. Visual materials.
6. Existing section drafts.
7. Existing chapter drafts.
8. Legacy chaotic drafts.
```

Use old drafts near the end when:

- normal sources give no new material;
- a previous text may contain a useful missed idea;
- the user explicitly points to a draft as an example;
- a ready paragraph needs reverse engineering into a semantic point;
- we need to compare new draft logic with older text.

Do not let old drafts override current decisions without source-pass.

## Previous drafts as examples

If the user says a previous draft should be used as an example and points to the file, treat it as `draft example source`.

It may guide:

- structure;
- depth;
- source-pass style;
- semantic point cards;
- visual bridge;
- section/full-text candidate handling.

It must not be copied mechanically.

## Full-text generation

Full-text generation uses the same source discipline as topic drafting, but produces connected academic VKR text instead of topic/section draft workbench.
