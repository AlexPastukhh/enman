# VKR workflow source of truth

## Main workflow

```text
raw notes
→ cautious source handling
→ roadmap
→ source-pass
→ answers from sources
→ new questions
→ desired result coverage
→ topic draft or full-text version
```

## Source-pass rule

For `уточни`, `перепроверь`, `дай версию текста`, `обнови текст`:

1. identify sources;
2. check them;
3. answer what can be answered;
4. list contradictions/outdated material;
5. create new questions;
6. update topic draft or generate full-text version.

## Topic vs full-text output

```text
topic-draft chat → working semantic draft;
full-text chat → connected academic VKR text.
```

Both use the same source/question discipline.
