# Existing chapter drafts

This folder stores existing chapter drafts or large section drafts that were produced before the current workflow or outside it, but may still be useful.

They are **not final clean text** and **not source of truth**.

## Why keep them

Existing chapters may contain:

```text
usable structure;
successful explanations;
useful tables;
good transitions;
problem statements;
notes about what is missing;
examples of what to avoid.
```

## Suggested structure

```text
existing-chapter-drafts/
├─ README.md
├─ chapter-1/
├─ chapter-2/
├─ review-notes/
└─ extracted-materials/
```

## How to use

Run:

```text
planning/thesis/chat-action-algorithms/cleanup-and-legacy/existing-chapter-draft-review.md
```

Then reuse in two modes:

```text
idea / section candidate → topic draft material;
usable paragraph → section draft block with review note.
```

All reused material must pass:

```text
questions;
source support;
research/repo/visual check if needed;
overclaim check;
rewrite/edit.
```
