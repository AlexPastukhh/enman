# Section drafts

This folder stores developing VKR text.

## Main rule

Section drafts are built by blocks.

```text
topic semantic point
→ questions
→ source materials
→ plan of disclosure
→ section draft block
→ candidate text
→ review/edit
```

Do not create a section draft as a single uncontrolled text wall.

## Existing chapter drafts can be used

If there is an existing chapter draft with useful text, it can be used only after review:

```text
planning/thesis/chat-action-algorithms/cleanup-and-legacy/existing-chapter-draft-review.md
planning/thesis/chat-action-algorithms/cleanup-and-legacy/existing-section-draft-reverse-engineering.md
```

Reuse modes:

```text
existing idea → topic draft material candidate;
existing semantic point → topic draft semantic point;
existing paragraph → section draft block with review note;
existing problem → question/checklist;
existing table → table candidate with source/format checks.
```

## Existing chapters as section draft candidates

Current existing chapters may be used as initial section draft candidates.

That means:

```text
existing text remains on the section-draft side;
topic draft contains reverse-engineered semantic points;
section draft is corrected through those points.
```

Do not move whole existing text blocks into topic drafts.

## No fragment bank

There is no mandatory `fragment-bank.md`. Section draft itself is where text accumulates.

If a generated paragraph is good, put it into the relevant section block. If its place is unclear, return to the topic draft and decide the semantic point / section block.

## Required before writing or keeping a section block

1. Which topic draft feeds this block?
2. Which semantic point does the block express?
3. What is its purpose in disclosure?
4. What should be before and after it?
5. Which question does the block answer?
6. Which source materials support it?
7. Does it need research bridge?
8. Does it need repo/evidence check?
9. Does it need a visual?
10. What overclaim risk exists?
11. Does an existing chapter draft contain reusable material for this block?
12. Should the current text be kept, compressed, expanded, moved or rewritten?
