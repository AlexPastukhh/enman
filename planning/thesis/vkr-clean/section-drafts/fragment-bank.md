# VKR Fragment Bank — deprecated/support

Статус: deprecated / support only

Этот файл больше не является частью активного workflow.

## Почему deprecated

Активный workflow теперь не строится вокруг склада фрагментов. Вместо этого используется block-based section drafting:

```text
topic draft
→ смысловые блоки
→ вопросы к блокам
→ план раскрытия
→ соответствующие блоки section draft
→ постепенное написание текста внутри section draft
```

Хорошие абзацы не нужно складывать сюда как обязательный этап. Их нужно привязывать к конкретному блоку section draft.

## Что делать с прежним содержимым

Оригинал этого файла сохранён в safe-merge архиве:

```text
_archive-review/2026-05-19-vkr-workflow-block-drafting-v2/original-files/planning/thesis/vkr-clean/section-drafts/fragment-bank.md
```

Если в прежнем файле были полезные формулировки, их можно вручную перенести в конкретный section draft block или в notes соответствующего section draft.

## Не использовать для новых драфтов

Не добавлять сюда новые фрагменты. Новые материалы должны идти в:

```text
planning/thesis/vkr-clean/section-drafts/<chapter>/<section-draft>.md
```

или в соответствующий topic-драфт как вопросы/план раскрытия блока.
