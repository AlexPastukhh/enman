# Terminology

Status: draft

| Термин | Чистое определение для ВКР | Статус |
|---|---|---|
| ООО «ЗСК» | Условная сетевая компания, для которой разрабатывается web-приложение | draft |
| Сетевая компания | Организация, принимающая и обрабатывающая клиентские заявки, связанные с подключением или обслуживанием объектов | draft |
| Web-приложение | Клиент-серверная система, доступная через браузер и backend API | implemented/designed |
| Клиент | Пользователь, который регистрируется, входит в систему, создает заявителя и подает заявку | implemented/designed |
| Сотрудник | Пользователь со стороны сетевой компании, который просматривает и обрабатывает заявки | designed/planned |
| Аккаунт клиента | Учетная запись клиента с email, паролем, ролью и признаком активности | implemented |
| Заявитель | Лицо, от имени которого подается заявка | implemented/designed |
| Заявитель-физическое лицо | Заявитель с ФИО, email и телефоном | implemented |
| Клиентская заявка | Обращение клиента, содержащее данные заявителя, адрес объекта и описание требуемой услуги | implemented/designed |
| Заявка на подключение | Тип клиентской заявки, связанный с объектом и адресом подключения | implemented |
| Ручная проверка | Действия сотрудника по анализу данных заявки перед принятием решения | designed/planned |
| Одобрение заявки | Положительное решение сотрудника, после которого может быть создан проект договора или документа | designed/planned |
| Отклонение заявки | Отрицательное решение сотрудника с указанием причины или комментария | designed/planned |
| Проект договора | Документ или договорное предложение, формируемое после одобрения заявки | designed/planned |
| Email-уведомление | Сообщение клиенту о результате обработки заявки или появлении проекта документа | planned |
| Доменная модель | Представление основных сущностей, связей, состояний и ограничений предметной области | draft |
| Инвариант | Ограничение, которое не должно нарушаться при выполнении операций системы | draft |
| Интеграционный тест | Тест, проверяющий совместную работу API, приложения и базы данных | implemented |
