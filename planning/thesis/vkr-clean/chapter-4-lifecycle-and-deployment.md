# Chapter 4. Lifecycle And Deployment

Status: draft

## 4.1. Эксплуатация системы

Web-приложение предназначено для эксплуатации сотрудниками и клиентами сетевой компании. Клиентская часть доступна через браузер, backend предоставляет API и взаимодействует с базой данных.

Для эксплуатации системы требуется:

- сервер или рабочая среда для ASP.NET Core приложения;
- база данных SQL Server;
- frontend-сборка React/TypeScript;
- настройка подключения к базе данных;
- настройка HTTPS;
- настройка почтового сервиса для email-уведомлений, если функция включена.

## 4.2. Внедрение

Внедрение системы может выполняться поэтапно:

1. Развертывание базового контура регистрации и подачи заявок.
2. Подключение рабочего места сотрудника.
3. Добавление ручной проверки и изменения статусов заявок.
4. Добавление создания проекта договора или документа.
5. Подключение email-уведомлений.
6. Расширение документооборота и аналитики.

Такой подход снижает риски внедрения и позволяет сначала проверить основной поток обработки заявки.

## 4.3. Безопасность

Для системы важны следующие меры безопасности:

- аутентификация клиентов и сотрудников;
- хранение паролей в виде хеша;
- проверка принадлежности заявителя и заявки текущему клиенту;
- запрет доступа клиента к чужим заявкам и документам;
- разграничение клиентских и сотруднических действий;
- защита API от некорректных запросов;
- использование HTTPS.

## 4.4. Ограничения текущей версии

Текущая версия материалов разделяет реализованный базовый срез и целевую версию системы.

Реализованный срез подтверждает базовые операции клиента. Полный цикл обработки заявки сотрудником, создание проекта договора и email-уведомление необходимо дополнительно подтвердить кодом или оставить как проектируемую/планируемую часть.

## 4.5. Направления развития

В дальнейшем систему можно развивать в следующих направлениях:

- расширение типов заявителей: юридические лица и индивидуальные предприниматели;
- расширение типов заявок;
- полноценный электронный документооборот;
- статусы подписания договора;
- хранение версий документов;
- email-уведомления и уведомления в личном кабинете;
- панель сотрудника с фильтрами и очередью заявок;
- аналитика по срокам обработки заявок;
- интеграция с внешними сервисами и учетными системами.
