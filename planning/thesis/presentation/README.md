# Presentation Materials

Status: draft

## Тема

«Разработка web-приложения для автоматизации ведения документооборота и обработки клиентских заявок в сетевой компании ООО „ЗСК“»

## Назначение

Папка `planning/thesis/presentation/` содержит материалы для защиты ВКР:

- план презентации;
- структуру слайдов;
- текст доклада;
- демонстрационный сценарий;
- список нужных визуальных материалов.

## Защитная логика

Презентация должна идти по понятной линии:

1. Тема и организация.
2. Предметная область.
3. Проблема ручной обработки заявок и документов.
4. Цель и задачи.
5. Пользователи системы.
6. Основные сценарии клиента.
7. Основные сценарии сотрудника.
8. Архитектура.
9. Доменная модель.
10. База данных.
11. Интерфейс.
12. Реализованные функции.
13. Тестирование.
14. Результаты.
15. Развитие.

## Важное разграничение

На защите нужно не смешивать:

- реализованный базовый срез: регистрация, вход, заявитель, заявка;
- проектируемую полную версию: обработка сотрудником, договор, email;
- будущие расширения: электронное подписание, аналитика, интеграции.
