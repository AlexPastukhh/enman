# Algorithm: Visual Material Review

Когда пользователь присылает рисунки/диаграммы/таблицы:

```text
1. Определить, к какой теме/пункту ВКР они относятся.
2. Проверить, не конфликтует ли нумерация с текущей структурой главы.
3. Для каждого визуала сказать: оставить / упростить / перенести / сделать таблицей / в приложение / в презентацию.
4. Проверить, нет ли overclaiming на рисунке.
5. Указать, какие внутренние заметки убрать из финального рисунка.
6. Дать рекомендации визуальному чату.
7. Сказать, один это рисунок или пакет визуалов.
```

Внутренние блоки вроде `Смысл рисунка`, `Как использовать`, `Для ПЗ лучше таблица` обычно переносить в пояснение после рисунка или в visual brief.
