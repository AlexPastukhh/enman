# Full text generation algorithms

This folder contains algorithms for chats that generate connected VKR text versions.

These chats do not create topic drafts or section draft workbenches as their main result. They generate coherent academic text versions for VKR points, subsections, chapters or the whole thesis.

## Files

```text
vkr-full-text-version-generation.md
```

## Main principle

Full-text generation uses the same source discipline as topic drafting:

```text
source-pass
→ answers from sources
→ new questions
→ cautious decisions
→ coherent VKR text version
```

But the output is different:

```text
topic-draft chat → working semantic draft;
full-text chat → connected academic VKR text.
```

## Forbidden inside VKR text

Do not include internal workflow language inside the generated thesis text:

```text
roadmap;
topic draft;
section draft;
raw notes;
semantic point;
source-pass;
chat;
prompt;
workflow;
AI;
L1/L2.
```

These can be mentioned only in the external commentary before/after the text, not inside the VKR text itself.
