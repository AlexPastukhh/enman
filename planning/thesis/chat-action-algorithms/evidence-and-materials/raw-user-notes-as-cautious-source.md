# Algorithm: raw user notes as a cautious source

Run this when user notes, rough thoughts, pasted discussion fragments or draft comments are used as material for VKR drafting or full-text generation.

## Core rule

Raw user notes are a source, but they are a cautious source.

They can contain:

- project intent;
- decisions;
- doubts;
- topic ideas;
- future section ideas;
- useful wording;
- risks and guardrails;
- links between chapters;
- possible semantic points.

But they are not:

- final VKR text;
- factual evidence;
- research;
- repo evidence;
- clean requirements;
- proof that something is implemented.

## Required handling

```text
raw user note
→ preserve sufficiently, not too compressed
→ mark as raw/cautious
→ assign possible location
→ identify material type
→ attach to desired result / semantic point / roadmap item
→ rephrase before section/full text
→ check if needed
```

## Preservation level

A good roadmap record should include:

```text
ID;
raw note or faithful expanded summary;
possible places;
why it matters;
how to use;
risk / caution;
status.
```

## Caution labels

```text
raw / cautious;
needs rephrasing;
research needed;
scenario/domain check needed;
repo-check needed;
visual decision needed;
accepted decision;
deferred;
rejected.
```

## Final text rule

Never paste raw notes into final VKR text. Rewrite academically and check factual claims.
