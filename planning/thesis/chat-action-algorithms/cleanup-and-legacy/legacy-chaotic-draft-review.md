# Algorithm: legacy / chaotic draft review

Run when the user provides a weak, chaotic or clearly outdated VKR chapter draft.

## Required behavior

1. Do not treat it as clean section draft.
2. Store/use it under:

```text
planning/thesis/vkr-clean/legacy-chaotic-drafts/
```

3. Review:
   - what is useful;
   - what is inaccurate;
   - what is too generic;
   - what overclaims implementation;
   - what conflicts with current workflow;
   - what can be salvaged.
4. Do not copy text directly.
5. Use only as material for topic/section block discussion.

## If the draft is not actually bad

If review shows that the existing chapter is coherent and useful, move/categorise it as:

```text
planning/thesis/vkr-clean/existing-chapter-drafts/
```

and run `existing-chapter-draft-review.md` instead.
