# Cleanup, legacy and existing drafts algorithms

This folder contains mandatory algorithms for old, weak, chaotic or pre-existing VKR texts.

## Files

```text
legacy-chaotic-draft-review.md
existing-chapter-draft-review.md
existing-section-draft-reverse-engineering.md
```

## Difference

```text
legacy-chaotic-drafts/
  weak or chaotic texts created outside workflow; use only for analysis and cleanup.

existing-chapter-drafts/
  existing chapter drafts that may be useful; treat them as secondary resources and section draft candidates.
```

## Current workflow with existing chapters

Existing chapters are not ignored and are not treated as trash. They can contain useful structure, wording, tables and problem notes.

But they are not source of truth and not final clean VKR text.

Use them through reverse engineering:

```text
existing chapter / subsection
→ section draft candidate
→ semantic points
→ topic draft questions and checks
→ updated section draft blocks
```

## Which algorithm to use

```text
existing-chapter-draft-review.md
  Use for high-level review of existing chapters: what is good, risky, reusable, missing.

existing-section-draft-reverse-engineering.md
  Use when converting an existing section/subsection into semantic points and section draft blocks.

legacy-chaotic-draft-review.md
  Use for weak/chaotic drafts created outside the workflow; mainly to extract warnings and salvageable ideas.
```

## Main rule

Existing chapters may feed topic drafts and section drafts, but they must not bypass topic-draft workflow.
