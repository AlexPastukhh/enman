# Drafting algorithms

This folder contains mandatory algorithms for topic drafts and section drafts.

## Files

```text
topic-draft-default-flow.md
  Run on “дай драфт / давай драфт / обнови драфт”.

topic-clarify-and-recheck-flow.md
  Run on “уточни / перепроверь / проверь всё”.

topic-to-section-block-drafting.md
  Explains how topic semantic blocks become section draft blocks.

section-draft-generation.md
  Run when the user asks for section draft text.

question-generation-for-drafts.md
  Required question levels for drafts.

question-priority.md
  How to choose which questions to ask now.
```

## Main drafting rule

```text
topic draft → section blocks → questions → source support → plan → text inside section draft
```

Do not write one uncontrolled wall of text.
