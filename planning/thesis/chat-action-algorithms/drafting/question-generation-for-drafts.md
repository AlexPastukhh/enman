# Algorithm: question generation for drafts

Every topic draft must contain strong questions.

## Five question levels

1. Topic questions: what exactly is being disclosed?
2. Subsection questions: why is this needed in this VKR subsection?
3. Chapter questions: how does this support the chapter logic?
4. Evidence questions: what is confirmed by repo/slices/domain/scenarios?
5. Section draft questions: how should this become text?

## Priority

Use `question-priority.md`. Questions must be chosen by current usefulness, not by quantity alone.

Priority order:

```text
blocking;
strong;
research;
repo/evidence;
visual;
style.
```

## Each question should include

```text
priority;
why it matters;
what happens if unanswered;
default answer;
alternative variants;
where the answer goes in section draft.
```

## Goal

Questions are not decoration. They are a production mechanism for better topic drafts and section drafts.
