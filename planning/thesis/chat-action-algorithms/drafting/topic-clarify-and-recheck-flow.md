# Algorithm: clarify and recheck topic draft

Run when the user says:

```text
уточни
перепроверь
проверь всё
что не так
какие ошибки
что улучшить
```

## Required behavior

1. Do not immediately write a new large draft.
2. Determine the relevant topic/chapter.
3. Check relevant sources for that chapter.
4. Identify:
   - what is confirmed;
   - what is doubtful;
   - what is not proven;
   - what may be overclaim;
   - what conflicts;
   - what is missing;
   - what questions should be asked.
5. Propose corrections.
6. Propose default answers and alternatives.
7. State what should be added to the next draft.

## Required source check

When the user asks to clarify/recheck, the chat must look beyond the current text and use relevant topic materials: scenarios, DATA, domain, slices, research, visuals, repo/evidence, questions/decisions where appropriate.
