# Algorithm: Topic Draft Generation

Когда пользователь просит topic-драфт:

```text
1. Показать карту размещения в ВКР и workbench.
2. Объяснить, что это за тема.
3. Разложить тему на смысловые блоки.
4. Для каждого блока найти вопросы.
5. Сформировать блоки будущего section draft.
6. Добавить research bridge, если нужен.
7. Добавить repo/evidence questions, если есть риск overclaiming.
8. Добавить visual bridge.
9. Добавить границы утверждений.
10. Добавить карту будущего текста.
11. Добавить вопросы для конкретизации.
12. Закончить итоговой формулой темы.
```

Не писать финальный текст ПЗ вместо topic-драфта, если пользователь просит именно драфт темы.
