# Algorithm: Section Draft Generation

Когда пользователь просит текст раздела или section draft:

```text
1. Найти topic-драфт, который является смысловой базой.
2. Определить блоки section draft.
3. Проверить, какие вопросы по блокам уже закрыты.
4. Закрыть research bridge, если есть внешние тезисы.
5. Закрыть repo/evidence check, если речь о реализации.
6. Учесть visual bridge: где рисунки, таблицы, скриншоты.
7. Написать section draft по блокам, не одним хаотичным текстом.
8. Оставить TODO SOURCE / TODO FIGURE / TODO CHECK REPO там, где не закрыто.
```

Если topic-драфта нет, можно сделать exploratory draft только с явной пометкой `exploratory / incomplete`.
