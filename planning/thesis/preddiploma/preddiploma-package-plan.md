## Центральный нарратив

```text
клиент
→ заявитель
→ заявка на обслуживание / подключение
→ рассмотрение сотрудником
→ решение
→ договорно-документный обмен
→ уведомление / обратная связь
```

Важные ограничения:

```text
Email-уведомления пока не писать как гарантированно реализованные без repo-check.
Договорная часть реализована как agreement exchange с document metadata references,
а не как полноценное бинарное файловое хранилище.
```
