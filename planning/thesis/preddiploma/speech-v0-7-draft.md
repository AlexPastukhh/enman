# Доклад v0.7

Status: draft / target 6–7 minutes

Уважаемые члены комиссии, вашему вниманию представляется выпускная квалификационная работа на тему: «Разработка web-приложения для автоматизации ведения документооборота и обработки клиентских заявок в сетевой компании ООО „ЗСК“».

Актуальность работы связана с тем, что обработка клиентской заявки обычно не ограничивается только её регистрацией. В процессе участвуют клиент, заявитель и сотрудник организации. После подачи заявки необходимо проверить данные, принять решение, при положительном результате перейти к договорно-документному этапу и обеспечить обратную связь с клиентом.

Целью работы является разработка web-приложения, которое поддерживает подачу клиентских заявок, их рассмотрение сотрудником, связь с договорно-документным обменом и подготовку основы для обратной связи с клиентом.

Для достижения цели были выполнены анализ предметной области, сравнение существующих решений, формирование требований, проектирование сценариев, доменной модели, базы данных и API-контракта, реализация серверной и клиентской частей, а также тестирование основных сценариев.

В предметной области основной процесс можно представить как цепочку: клиент создаёт или использует данные заявителя, подаёт заявку, сотрудник рассматривает её, принимает решение, а после положительного решения начинается договорно-документный обмен.

Разрабатываемое приложение построено как клиент-серверная система. Backend реализуется на ASP.NET Core, frontend — на React и TypeScript. Для согласования серверной и клиентской частей используется API-контракт: OpenAPI-описание, generated TypeScript types и typed API wrappers.

В доменной модели выделяются клиентский аккаунт, заявитель, заявка, результат рассмотрения, сотрудник, договорный обмен, предложение и ссылка на договорный документ. В текущем срезе договорный документ представлен через ссылку и метаданные. Полноценное файловое хранилище с загрузкой и скачиванием файлов рассматривается как направление дальнейшего развития.

В клиентской части реализованы сценарии регистрации и входа, работы с заявителем, создания заявки, просмотра списка и деталей заявок. Для сотрудника реализованы экран очереди заявок, карточка заявки и действия по рассмотрению: начало рассмотрения, одобрение и отклонение.

Договорно-документный обмен реализован как отдельный процесс, связанный с заявкой. Он включает список обменов, карточку обмена, версии предложений и действия принятия или финального отказа.

Для проверки приложения используются доменные тесты, интеграционные тесты API, frontend-тесты, Playwright E2E-тесты и проверки контрактных артефактов.

В результате работы разработан текущий срез web-приложения, который покрывает основные пользовательские линии: клиентскую подачу заявки, рассмотрение заявки сотрудником и договорно-документный обмен.

К ограничениям текущей версии относятся физическое файловое хранилище документов, скачивание файлов, email-уведомления, электронное подписание и производственный deploy. Эти направления могут быть реализованы в дальнейшем развитии системы.

Спасибо за внимание.
