# Преддипломная практика и комплект ВКР v0.7

Status: working package / fast drafting baseline  
Scope: сборка проверяемого комплекта для преддипломной практики и предзащиты

Этот каталог нужен для быстрой сборки комплекта:

```text
отчёт по преддипломной практике
+ пояснительная записка ВКР v0.7
+ презентация v0.7
+ доклад v0.7
+ скриншоты / диаграммы / таблицы
+ checklist недостающих материалов
```

## Основная цель

Получить структурно полный и проверяемый комплект, который можно показать руководителю, использовать для закрытия преддипломной практики и затем дорабатывать по замечаниям.

Рабочий уровень качества:

```text
v0.7 = все разделы есть, логика понятна, реализация описана осторожно,
визуалы запланированы, TODO-маркеры сохранены там, где нужна проверка кода,
источника, скриншота или нормоконтроля.
```

## Правило

В этом пакете допустимы:

```text
TODO SOURCE
TODO INSERT FIGURE
TODO INSERT TABLE
TODO INSERT SCREENSHOT
TODO CHECK REPO
TODO CHECK EMAIL
TODO UPDATE AFTER IMPLEMENTATION
```

Нельзя утверждать как завершённое то, что не проверено по текущему коду.
