# Implementation Status For Preddiploma

Status: repo-observed working baseline

## Можно описывать как реализованное после repo-check

### Клиентский поток

```text
- регистрация клиентского аккаунта;
- вход клиента в систему;
- получение текущего пользователя;
- выход из системы;
- создание заявителя-физического лица;
- получение списка заявителей аккаунта;
- получение текущего/default заявителя;
- создание заявки на подключение / обслуживание;
- просмотр списка заявок клиента;
- просмотр деталей заявки клиента;
- фильтрация списка заявок клиента.
```

Формулировка:

```text
В клиентской части реализован базовый пользовательский поток:
регистрация и вход, создание заявителя, подача заявки, просмотр списка и деталей заявок.
```

### Сотруднический поток

```text
- рабочая часть сотрудника;
- очередь/панель заявок;
- фильтрация заявок;
- просмотр деталей заявки;
- начало рассмотрения;
- одобрение;
- отклонение с обратной связью;
- переход к запуску договорно-документного обмена после положительного решения.
```

Формулировка:

```text
Для сотрудника реализован рабочий срез рассмотрения заявок:
просмотр очереди, открытие карточки заявки, начало рассмотрения, одобрение или отклонение.
```

### Договорно-документный обмен

```text
- запуск agreement exchange по заявке;
- создание первой версии предложения сотрудником;
- отправка последующих версий предложения;
- список agreement exchanges;
- детали agreement exchange;
- просмотр истории предложений;
- принятие активного предложения клиентом;
- финальный отказ сотрудника.
```

Формулировка:

```text
Реализован срез договорно-документного обмена, в котором по одобренной заявке
создаётся обмен предложениями, а каждая версия предложения содержит ссылку на договорный документ
и его метаданные.
```
