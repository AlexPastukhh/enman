# Document Storage Wording Note

Status: wording guardrail

## Что реализовано

Правильная граница:

```text
agreement exchange
+ agreement proposal versions
+ document metadata reference
```

То есть договорно-документный обмен есть, но полноценное файловое хранилище не следует заявлять без отдельной реализации.

## Формулировка для ПЗ

```text
В рамках договорно-документного этапа реализована модель обмена предложениями договора.
Каждая версия предложения связывается с документной ссылкой, включающей ключ хранения,
исходное имя файла, тип содержимого и размер. Такой подход позволяет связать договорный документ
с конкретной заявкой и историей согласования, не смешивая бизнес-логику обмена
с физическим хранением файлов.
```

## Формулировка для ограничений

```text
В текущей версии хранится ссылка на документ и его метаданные.
Физическая загрузка, безопасное хранение, скачивание и проверка файлов
рассматриваются как направление дальнейшего развития.
```

## Чего избегать

```text
- реализовано полноценное документохранилище;
- файлы договоров загружаются и скачиваются;
- реализована безопасная выдача файлов;
- реализовано хранение PDF;
- реализовано электронное подписание.
```
