# VKR topic workbench

This folder stores topic drafts, chapter roadmaps, drafting rules and research/visual planning materials for the VKR.

## Main files

```text
VKR-DRAFTING-ROADMAP.md
00-inbox/
00-workflow-and-rules/
01-introduction/
02-chapter-1-analysis/
03-chapter-2-design/
04-chapter-3-implementation/
05-conclusion/
06-preddiploma-derivatives/
```

## Roadmap layer

Use the roadmap layer for cross-chapter and future notes.

```text
VKR-DRAFTING-ROADMAP.md
02-chapter-1-analysis/CHAPTER-1-ROADMAP.md
03-chapter-2-design/CHAPTER-2-ROADMAP.md
04-chapter-3-implementation/CHAPTER-3-ROADMAP.md
```

## Why there are several roadmaps

```text
VKR-DRAFTING-ROADMAP.md
→ whole VKR picture, raw notes, cross-chapter decisions

CHAPTER-X-ROADMAP.md
→ chapter-level planning and distribution
```

Topic drafts should not carry every future note. They may reference roadmap notes when needed.

## Capture-first rule

If the user gives many notes or future ideas, capture them first:

```text
raw notes
→ VKR-DRAFTING-ROADMAP.md
→ CHAPTER-X-ROADMAP.md
→ topic draft
→ section draft block
```

Do not overload the current topic draft with all future notes.

## Topic drafts

Topic drafts are `.topic.md` files. They contain semantic points, questions, checks, sources, visual/research bridges and section block plans.

They are not final VKR text.
