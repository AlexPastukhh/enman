# VKR topic workbench

This folder stores topic drafts — semantic working bases for VKR sections.

## Main rule

Topic drafts are not final thesis text. They feed section drafts through questions, source materials, research bridge, visual bridge and section blocks.

## Topic drafts location

```text
planning/thesis/vkr-topic-workbench/**/*.topic.md
```

## Topic-to-section workflow

Read:

```text
TOPIC-TO-SECTION-BLOCK-WORKFLOW.md
```

## Workflow rules

```text
00-workflow-and-rules/
```

## Resource map

For all VKR resources, read:

```text
planning/thesis/VKR-RESOURCE-MAP.md
```

## Existing chapter drafts

Existing chapters are not stored here. They live in:

```text
planning/thesis/vkr-clean/existing-chapter-drafts/
```

If they contain useful material, extract it into topic drafts as material candidates or into section draft blocks after review.
