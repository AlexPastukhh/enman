Raw notes are cautious sources: preserve, classify, rephrase, check if needed.

## Source priority

Old ready chapters, old drafts and legacy chaotic drafts are useful candidate material, but they should not be the first source for a new topic draft.

Default priority:

```text
active topic drafts / roadmap
→ scenarios/domain/process rules
→ research
→ visuals
→ existing section drafts
→ existing chapter drafts
→ legacy chaotic drafts
```
