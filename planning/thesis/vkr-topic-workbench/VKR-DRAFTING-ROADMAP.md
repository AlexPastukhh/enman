# VKR drafting roadmap

This file stores high-level planning, raw notes and cross-chapter decisions.

## Current important decisions

| Decision | Reason | Applies to |
|---|---|---|
| Raw notes are cautious sources | They preserve intent but are not clean text/proof | all drafting |
| Source-pass is required before clarify/full-text generation | Avoids rewriting only from user memory | topic/full-text chats |
| Source-pass results go into the topic draft | Draft accumulates checked logic | topic drafts |
| Existing chapters 1-2 are valid candidate drafts | Do not lose useful existing text | chapters 1-2 |
| Full-text chat uses same source/question logic as topic chat | It must not generate from air | text versions |
| Chapter 1 uses scenarios/domain rules over code | Chapter 1 is analysis, not implementation | chapter 1 |
| Linear visuals may be tables rather than figures | Avoid weak redundant diagrams | visuals |
