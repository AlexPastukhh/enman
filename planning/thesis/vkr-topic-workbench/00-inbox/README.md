# VKR workbench inbox

This folder stores raw notes that should not be lost but are not yet distributed into chapter roadmaps, topic drafts or section drafts.

## Main rule

```text
raw notes / discussion material
→ VKR-DRAFTING-ROADMAP.md
→ CHAPTER-X-ROADMAP.md
→ topic draft semantic points
→ section draft blocks
```

Do not force every note into the current topic draft immediately.

First capture the shared picture in the general roadmap, then distribute only relevant parts into concrete drafts.

## Raw notes

Raw notes should be kept under:

```text
00-inbox/raw-notes/
```

Each raw note should later be reflected in roadmap distribution tables or rejected/deferred explicitly.
