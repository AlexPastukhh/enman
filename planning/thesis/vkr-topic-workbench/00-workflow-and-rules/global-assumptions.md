# Global Assumptions

Status: initial

## A1. Topic workbench comes before drafts

The workbench collects meaning, material and visuals before creating polished section drafts.

## A2. Top-level folders represent mandatory VKR blocks

Top-level folders are not internal engineering topics. They reflect base thesis structure.

## A3. L1/L2 are internal planning labels

Do not use `L1` / `L2` as thesis structure labels. Use domain/project wording instead.

## A4. DDD wording should be careful

Prefer:

```text
применяются отдельные принципы предметно-ориентированного проектирования
```

Avoid making the thesis sound like a theoretical DDD dissertation unless the section specifically needs it.

## A5. Document storage wording must be cautious

Current wording should be:

```text
договорно-документный обмен;
версии предложений;
ссылка на документ и метаданные;
```

Future/deferred:

```text
binary upload/download;
storage adapter;
secure file serving;
email notifications.
```

## A6. Visuals personalize the thesis

Use diagrams, screenshots and tables to tie each claim to the actual project.
