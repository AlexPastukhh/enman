```text
ВКР
├─ Введение

│  ├─ 1.1 Характеристика процесса обработки клиентских заявок в сетевой компании
│  │  └─ Текущая тема: Процесс обработки клиентской заявки
│  ├─ 1.2 Договорно-документный этап и обратная связь с клиентом
```

## Пример описания рисунка

### Рисунок 1.1 — Укрупнённый процесс обработки клиентской заявки

**Где стоит в тексте:** после вводного абзаца о процессе обработки заявки.

**Что читатель должен увидеть:** заявка является частью цепочки, а не отдельной формой.

**Для чего нужен:** показать предметную основу ВКР и связь заявки с дальнейшим документным этапом.

**Что должно быть на рисунке:**

```text
Клиент
→ личный кабинет
→ заявитель
→ заявка
→ сотрудник
→ решение
→ договорно-документный этап
```

**Что нельзя показывать:** технологии, API, БД, тесты, внутренние implementation labels.

**Подпись:** Рисунок 1.1 — Укрупнённый процесс обработки клиентской заявки в сетевой компании.

**Пояснение после рисунка:** заявка связывает клиента, заявителя, сотрудника и решение, а при положительном результате ведёт к договорно-документному этапу.

## Пример границ утверждений

```text
демонстрационная проверка данных показывает место будущей интеграции.
```

```text
реализована внешняя проверка данных.
```
