# Правило использования предыдущих тем как примеров

Статус: актуально

## Основное правило

Если пользователь просит новый драфт темы и не задаёт другой формат, использовать предыдущие принятые темы как явные примеры.

Использовать как пример:

```text
структуру;
карту размещения;
глубину обсуждения;
способ описания рисунков;
карту будущего текста;
границы утверждений;
русский язык оформления.
```

Не использовать как пример:

```text
конкретное содержание, если тема другая;
устаревшие решения;
английские статусы и workflow labels;
внутренние implementation labels;
```

## Текущий пример

Для текущего этапа примером считается тема:

```text
Глава 1 → 1.1 → Процесс обработки клиентской заявки
```

и примерный файл:

```text
planning/thesis/vkr-topic-workbench/02-chapter-1-analysis/01-domain-process/01-client-request-process.topic.md
```

Если эта тема позже будет обновлена, использовать её последнюю принятую версию.

## Как ссылаться в новых драфтах

В начале нового драфта можно писать:

```text
Формат драфта: по принятому примеру темы 1.1 “Процесс обработки клиентской заявки”.
```

Это означает:

```text
карта главы;
карта workbench;
роль темы;
содержание;
обоснования;
уровни раскрытия;
границы утверждений;
точное описание рисунков;
карта будущего текста;
черновые фрагменты;
открытые вопросы.
```
