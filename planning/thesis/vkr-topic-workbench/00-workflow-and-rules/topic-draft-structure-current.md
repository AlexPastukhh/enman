# Current topic draft structure

## Main model

```text
raw notes
→ cautious source handling
→ roadmap
→ source-pass
→ desired result coverage
→ semantic point discovery
→ existing candidate intake
→ topic draft
→ full-text/section blocks
```

## Important rules

1. Source-pass is part of the topic draft after clarification.
2. Existing chapters 1-2 are valid candidate material, not garbage.
3. Raw notes are cautious sources.
4. Chapter 1 uses scenarios/domain rules before code.
5. Full-text generation uses the same source-pass discipline but outputs VKR text.
