# Author Voice And Message Capture Protocol

Status: initial

## Purpose

The author's raw messages are valuable because they contain project reasoning, doubts, priorities and living formulations. They should be stored separately from workflow rules and final text.

## Main rule

Before creating a replacement/archive package, the assistant must state in chat which user messages will be captured into:

```text
00-workflow-and-rules/author-materials/raw-author-message-log.md
```

## What to capture

Capture messages that contain:

```text
workflow decisions;
structure decisions;
author reasoning;
important doubts;
terminology preferences;
style preferences;
project-specific explanation;
concerns about dead/generic text;
```

Do not capture:

```text
short confirmations;
repeated messages unless they add meaning;
messages with no durable decision;
```

## Status

For now author messages are stored raw and not processed.

Future files may be added later:

```text
distilled-author-insights.md
author-formulation-bank.md
```

But v1 stores only raw messages.

## Warning

Raw author messages are not final thesis text, not approved rules and not polished formulations. They are source material for later review.
