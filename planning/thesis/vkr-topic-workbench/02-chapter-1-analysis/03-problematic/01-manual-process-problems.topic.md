# Topic: Проблематика ручного ведения заявок, документов и уведомлений

Status: material-harvest-needed

## 1. Зачем эта тема нужна

This topic turns the domain description into a reason for automation.

## 2. Куда входит

ПЗ:
- 1.3 Проблематика ручного ведения заявок, документов и уведомлений.

## 3. Что нужно добиться

Преподаватель должен понять:
- what concrete problems exist;
- how they affect client, employee and document flow;
- why web automation is justified.

## 4. План раскрытия темы

Flow:
1. State that manual/disconnected handling creates traceability problems.
2. Group problems by data, status, document link and feedback.
3. Convert problems into requirements in the next point.

## 5. Запланированная реализация раскрытия

Use a problem matrix instead of generic claims about automation.
