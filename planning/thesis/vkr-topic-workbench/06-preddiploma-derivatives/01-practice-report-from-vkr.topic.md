# Topic: Отчёт по ПП как производная от ВКР

Status: accepted-workflow

## 1. Зачем эта тема нужна

Отчёт по преддипломной практике нужен, но он не должен становиться отдельным центром работы. Его рациональнее собирать как сокращённую версию материалов ВКР: анализ, проектирование, реализация, подготовка презентации и доклада.

## 2. Куда входит

ПЗ:
- не входит напрямую, но использует её материалы.

Отчёт по ПП:
- весь отчёт.

Презентация:
- структура презентации берётся из ПЗ.

Доклад:
- доклад берётся из презентации и ПЗ.

## 3. Что нужно добиться

Преподаватель должен понять:
- в ходе ПП подготовлены материалы ВКР;
- есть предварительная ПЗ;
- есть практическая часть;
- есть презентация/доклад/визуалы;
- отчёт не противоречит ВКР.

Нужно обязательно раскрыть:
- выполненные работы;
- связь с темой ВКР;
- подготовка ПЗ;
- подготовка защиты;
- дальнейшие доработки.

Нужно показать:
- список приложений/материалов;
- визуальные доказательства разработки.

## 4. План раскрытия темы

Flow:
1. Указать тему ВКР.
2. Кратко описать выполненные работы.
3. Показать, что материалы ВКР подготовлены.
4. Перечислить практические результаты.
5. Указать, что презентация и доклад подготовлены/готовятся на основе ПЗ.

## 5. Запланированная реализация раскрытия

Берём:
- preliminary explanatory note;
- topic workbench summaries;
- screenshot/diagram plan;
- implementation status;
- presentation/speech outline.

Подаём так:
- коротко;
- не дублировать всю ПЗ;
- ссылаться на ПЗ как приложение/отдельный материал.

Обосновываем так:
- ПП — этап подготовки ВКР и предзащиты.

Вставляем визуалы:
- 4-6 ключевых screenshots if ready.

Ссылки/источники:
- mostly not needed except methodical requirements if final report requires.

Repo-check:
- update implementation status before final report.

Research:
