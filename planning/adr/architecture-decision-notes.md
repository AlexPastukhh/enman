# Architecture Decision Notes

Status: active accepted-decision notes  
Scope: accepted/current architecture decisions that are useful for implementation planning and diploma explanation

## 1. Purpose

This file collects accepted architecture decisions before they are promoted into full numbered ADRs.

A decision note means:

```text
This direction is accepted/current enough to guide planning,
but it is not yet a full ADR.
```
